# Disclaimer

Takibo is a research-oriented IAM engineering project under active development.

The goal of this repository is to explore, design, and validate advanced IAM architecture patterns, including identity management, OAuth2/OpenID Connect concepts, multi-tenant authorization, adaptive security decisions, auditability, and modular security boundaries.

Takibo is not yet a certified, externally audited, or production-ready IAM distribution. Although security is a core design objective of the project, any production deployment requires an independent security review, proper configuration, secret management, infrastructure hardening, load testing, and compliance validation.

Do not use default, sample, or development configurations in production environments.

This software is provided as-is, without warranty. Users are responsible for assessing whether Takibo is suitable for their own security, legal, operational, and compliance requirements.
